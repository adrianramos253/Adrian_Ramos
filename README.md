## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build tools or package installation are required. An internet connection is needed to load the optional Google Fonts; the site remains usable if the font service is unavailable.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. The URL will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/personal-portfolio/`
7. Open the live URL on desktop and mobile to test navigation, layout, and assets.
